# COS344_HA
COS 344's Homework Assignment

# Running the project

To run this project locally, navigate to the src directory in your CLI of choise. Ensure you have access to 
C++11 as well as OpenGL 3.3 Core profile.

Then, run the following commands in order from within the src directory:
- make clean
- make
- make run

A window should be created. It takes a moment for the textures to load, after which you will be able to see the course
and course elements.
